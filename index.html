Safe Internet App

Utilities and data used to build a safe list of homepages and a small dashboard.

Open Dashboard

Project files

  • urls.txt — source URL list
  • urls.js — JS helper used by the dashboard
  • verified-homepages.jsonl — verification output
  • url-check-report.json — last run report
  • tools/ — project scripts

Usage

Open dashboard.html in a browser, or serve the folder with a local web server.
