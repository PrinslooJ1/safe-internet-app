Safe Internet App

Utilities and data used to build a safe list of homepages and a small dashboard.

Open Dashboard

About

This app now uses MongoDB in the cloud as the source of truth for all website data. All changes are automatically persisted to the database.

Previously stored in: urls.txt and browser localStorage. These files are no longer used.

Project files

  • urls.txt — original URL list (archived, no longer used)
  • urls.js — JS helper used by the dashboard
  • server.js — Node.js/Express backend connected to MongoDB
  • routes/websites.js — API endpoints for website CRUD operations
  • models/Website.js — MongoDB schema for websites

Usage

Run npm start to start the server on port 10000. The Node.js backend will:

  • Connect to MongoDB
  • Serve the dashboard HTML
  • Provide API endpoints for managing websites
